\section{Simulator Overview}
\label{sec:simulator}

Consider round $s$ on the ideal side of Figure~\ref{fig:model-simulation}.
The environment can inspect the garbling and its encrypted share packets
before the providers post their inputs.  Yet the first honest
label-committee member to speak must reveal a key that opens its packet to a
share of the correct label.  The simulator uses the interval between
these events.  To prepare the garbling it needs only the topology of the
round circuit $C_s$ of Figure~\ref{fig:round-circuit}.  At input closure,
$\FMPC$ gives it enough information to fix what everyone will see on
evaluation, just before the label committees start speaking.

\paragraph{Preparing the public sample.}
The simulator runs the ledger in Figure~\ref{fig:model-simulation},
using the pids supplied by ideal registration for application parties.
It runs the universal sampler's $\SimSetup$ and $\SimRO$ with a source
that remembers its answer to each exact description.  At allocation,
the simulator can recover $Q_s$ from the coin packets with the keys
it holds for the nonce committee.  Before any honest member releases
its key, it reserves $\SampleCircuit_s$, now fixed by $Q_s$ and the
allocation.  Other descriptions receive ordinary samples.  On the
first source call for the reserved description, it prepares
\[
   (\GC_s,\tau_s)\sample\SimGarble(1^\lambda,\Topo(C_s)).
\]
For each label committee it chooses uniform shares for the initially
corrupt members and encrypts them.  Each honest member's packet is
the ciphertext reserved with its delivery key by receiver NCE.  The
bundle also contains a delivery packet for each output pad and a fresh full-NCE public key for each input provider.
For each provider it keeps the corresponding reserved ciphertext.

\paragraph{Committing the inputs.}
The ideal task reports the index of each honest provider's selected
input at the start of the input phase.  If there is an entry, the
simulator knows its public component from the input notice.  It signs
that component together with the reserved ciphertext for this round
and provider.  The posting commits the selected input in $\FMPC$.  If corruption follows, $\FMPC$
reveals the secret component and the simulator explains the posted
ciphertext with a sender tape for that value.  If corruption comes
first, the same full-NCE simulator gives a receiver explanation for
a dummy message.  The simulator keeps the resulting decryption key,
interprets the first valid signed record as $C_s$ would, and submits
the corresponding input pair to $\FMPC$.  The signature binds the public component to the ciphertext.  The
first valid record remains binding even if its signer is corrupted
immediately afterward.

\paragraph{Opening one encoding.}
At input closure, $\FMPC$ supplies the common output $\ypub_s$ and
the output bits of corrupt recipients.  The simulator picks a uniform
masked bit $z_{s,j}$ for each still-honest recipient.  For a corrupt
recipient it uses the already fixed pad and sets
$z_{s,j}=\ysec_{s,j}\oplus r_{s,j}$.  With $z_s$ the resulting vector
and $\nu_s$ the public outgoing state length, it computes
\[
   c_s\sample\PKE.\Enc(\statepk_{s+1},0^{\nu_s}),\qquad
   X_s\sample\SimEncode(\tau_s,(c_s,z_s,\ypub_s)).
\]
The same $c_s$ becomes a public input to the successor.  The simulator
can thus pass state ciphertexts between rounds without learning
$\sigma_s$.  If an honest recipient is later corrupted, its ideal
record supplies $\ysec_{s,j}$, fixing the pad $r_{s,j}=z_{s,j}\oplus
\ysec_{s,j}$ that its delivery key must explain.

Write $X_s=(\GarbleAux,\widehat L_1,\ldots,\widehat L_{m_s})$.
The incoming state ciphertext, public input records, and successor
public key determine which committee will speak for each wire $w$.
In that committee the simulator completes the already exposed shares
to a sharing of $\langle\GarbleAux,\widehat L_w\rangle$
(Lemma~\ref{lem:sharing-completion}).  It explains each honest member's
packet as its resulting share \emph{before} that member posts its key.
Reconstruction therefore releases the one encoding $X_s$.  The other
committee's honest members remain silent.  Figure~\ref{fig:simulator-patches}
locates these calls in the protocol.  Section~\ref{sec:simulator-details}
gives the clock events and the tapes and histories disclosed on corruption.
