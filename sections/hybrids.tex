\subsection{Hybrid Proof Sketch}
\label{sec:hybrids}

The difficulty in replacing $c_s$ by an encryption of $\sigma_s$ is
that the successor's garbling contains the matching secret key.
We make this change while the successor is still generated from its
topology.  Only afterward do we restore the garbling that uses the key.
The hybrids of Section~\ref{sec:hybrid-lemmas} compare the output bit of
the same environment in each complete experiment.  In $H_0$ through $H_6$ the reduction runs $\FMPC$
internally and hence knows the secret inputs, private outputs, and
states needed for its challenges.

\paragraph{Restore the plaintexts before the garblings ($H_0$--$H_3$).}
Start with the guarded simulator.  Full NCE restores genuine input
keys and encryptions one provider at a time, including the sender tape
or receiver key required by the order of corruption and posting.
Next embed an IND-CPA challenge key as $\statepk_{s+1}$ and obtain an
encryption of either $0^{\nu_s}$ or $\sigma_s$.  The ciphertext enters the public
transcript and the successor's input.  Its secret key is never
disclosed, and the topology-only simulator for the successor needs
only its prescribed evaluation result at encoding.  Once every transfer encrypts
the true state, choose the output pads $r_s$ and outgoing encryption
coins $\rho_s$ at preparation.  For a still-honest recipient the unused pad is independent of the
transcript up to closure, so setting $z_{s,j}=\ysec_{s,j}\oplus r_{s,j}$
has the same law as choosing $z_{s,j}$ uniformly then.
This change of sampling order fixes the constants of $C_s$ before its
input is known.

\paragraph{Restore the garblings ($H_3$--$H_4$).}
At preparation the reduction submits the fully specified $C_s$ to
the adaptive garbling game.  At closure it has the public input string
\[
  \InputBits_s=(c_{s-1},\InputRecords_s,\statepk_{s+1}).
\]
Honest records decrypt to the committed inputs except on a correctness
failure.  For a corrupt record, the simulator used the same decryption
key, tape, and default rule as $C_s$.  The incoming ciphertext now
decrypts to the preceding ideal state, with empty state in round~1.
Consequently
\[
 C_s(\InputBits_s)=
 \bigl(\PKE.\Enc(\statepk_{s+1},\sigma_s;\rho_s),\,\ysec_s\oplus r_s,\,
       \ypub_s\bigr).
\]
This is precisely the tuple previously supplied to $\SimEncode$.
The garbling game can therefore supply either the simulated encoding or
the genuine encoding of $\InputBits_s$.  The reduction needs just this
one encoding to complete the selected sharings at closure.

\paragraph{Restore the deliveries and public sampling ($H_4$--$H_8$).}
Once all garblings are genuine, the reduction can generate both labels
for every wire.  It now prepares both sharings.  Conditional on the initially corrupt
shares, the selected sharing has exactly the same law as when completed
at release.  Honest members of the other committee stay silent.  Every delivery plaintext is now available
when its packet is prepared.  Receiver NCE restores the genuine
delivery ciphertexts and key-generation tapes, including the tapes
of members corrupted immediately after speaking.

At $H_6$ the source generates honest samples.  Robust reconstruction gives the selected encoding.  Correct evaluation
and pad decryption then give the ideal task's public and private outputs.
Here the proof bounds the probability of reaching a failed check.  For example, at reservation an
early query for $\SampleCircuit_s$ must have guessed its nonce.
In the experiment stopped at allocation, encryption hides the honest
nonce shares, and up to $t$ corrupt shares are independent of the nonce.
This argument counts even source queries made before the committee was
assigned.  The aggregate failure bound carries back through the same
hybrids by running an environment that returns $1$ on normal
termination while each guard returns $0$ (Section~\ref{sec:guard-hybrid-proof}).

In $H_7$ the protocol uses simulated sampler parameters and oracle
answers, and in $H_8$ it uses genuine setup and the random oracle.
To make the comparison using only registered keys and public samples,
the reduction runs the protocol in the sampler game.  It initially
retains the simulator's extra private coin evaluations at allocation,
so the stateful $\SimRO$ sees the same oracle calls.  The sampler's
consistency guarantee now applies to that execution.  After switching
to genuine parameters and a fixed random oracle, the extra evaluations
can be dropped exactly.  Section~\ref{sec:endpoint-hybrid-proof}
gives this comparison.  Each reduction treats the polynomially many
instances reached by its environment, so setup requires bounds only
on individual samples.
