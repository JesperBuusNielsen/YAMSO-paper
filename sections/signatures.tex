\subsection{One-Time Signatures}
\label{sec:signatures}

An input provider authenticates its input record using a one-time signature.  The algorithms are
\[
  (\sigvk,\sigsk)\sample\SigGen(1^\lambda),\qquad
  \sig\sample\Sign(\sigsk,m),\qquad
  \Verify(\sigvk,m,\sig)\in\{\top,\bot\}.
\]
An honestly generated signature verifies except with negligible probability.  Given $\sigvk$
and at most one chosen-message signature, producing a valid signature on a
fresh message before key exposure has negligible probability (Appendix~\ref{app:signatures}).
Key-generation and signing coins are disclosed on corruption.  One instantiation signs a collision-resistant digest of the input record
with Lamport's scheme~\cite{Lamport1979Signatures}.
