\subsection{Adaptive Universal Samplers}
\label{sec:universal-samplers}
\label{sec:universal-sampler-syntax}

A public parameter $U$ lets anyone sample a distribution specified by a
Boolean circuit $d$.  With public random oracle $H$, the two calls are
\[
  U\sample\Setup^H(1^\lambda),
  \qquad p_d\gets\Sample^H(U,d).
\]
For fixed $U,H,d$ the sample is deterministic.  The scheme fixes polynomial
bounds $(\ell,m,k)$ for the description length, random tape, and output of
$d\colon\bits^m\to\bits^k$.  Descriptions and outputs are padded, unused
random bits are ignored, and an invalid $\ell$-bit description outputs
$0^k$.  The circuit $d$ has no oracle gates.

\label{sec:ideal-samples}
The ideal source $\IdealSample(d)$ returns $d(r_d)$, choosing a private
uniform $r_d\in\bits^m$ independently for each new description string and
reusing it on repetition.  Descriptions may be chosen after seeing $U$
and earlier samples, with no setup-time bound on their number.
\emph{Adaptive universal sampling} lets a simulator reproduce $U$ and
the public oracle using this source.  Its calls are
\[
  (U,\SimState)\sample\SimSetup^{\IdealSample}(1^\lambda),
  \qquad (a,\SimState)\sample\SimRO^{\IdealSample}(\SimState,q).
\]
The second call answers each public oracle query $q$ and retains its updated
state for the next query. The resulting view is computationally
indistinguishable from the real one. Except with negligible probability,
every public evaluation recorded by the adversary agrees with the ideal source.

Hofheinz et al. obtain adaptive universal samplers from indistinguishability
obfuscation and one-way functions in the random-oracle model~\cite[full
version, Definition~4 and Theorem~3]{HofheinzEtAl2016UniversalSamplers}.
Appendix~\ref{app:universal-samplers} gives the real and ideal experiments.
