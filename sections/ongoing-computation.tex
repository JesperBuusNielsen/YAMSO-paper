\section{Universal Streams and Ongoing Computation}
\label{sec:ongoing}

The finite construction requires one bounded setup sample. We now formulate a
small extension in which a fixed sampling description receives a growing
sequence of public inputs and emits a prefix-preserving sequence of samples.
We use an indefinitely extensible garbling as motivation. The primitive and
its construction are open research topics.

\subsection{A universal sampler with streaming public input}

In an ordinary universal sampler, finite public parameters $U$ allow every
party to compute
\[
  p_d=\mathsf{Sample}(U,d)
\]
for a finite description $d$ of a sampling circuit. Ideally, $p_d$ is
distributed as $d(r_d)$ for hidden random coins $r_d$ associated with $d$
\cite{HofheinzEtAl2014UniversalSamplers}. Distinct descriptions receive
independent ideal coins.

A \emph{streamer description} $d$ is instead a finite description of a
randomized streaming circuit. Its circuit structure, hidden-state evolution,
and output wires are fixed by $d$. Public inputs $x_1,x_2,\ldots$ arrive one
at a time. On every finite input prefix, $d$ performs a finite computation and
writes a finite extension to a left-to-right, write-only output tape. The
description is prefix efficient if this work is polynomial in the security
parameter, $|d|$, the total input length, and the output length so far.

\paragraph{Proposed universal-streamer syntax.}
A universal streamer has public algorithms
\[
  U\leftarrow\mathsf{Setup}(1^\lambda),
  \qquad
  \mathsf{Sample}(U,d,x_1,\ldots,x_t)\longrightarrow D_t.
\]
Both $U$ and $d$ remain finite; only the public input sequence is extendible.
The output is exactly prefix preserving: for every continuation $x_{t+1}$,
\[
  \mathsf{Sample}(U,d,x_1,\ldots,x_t)
  \preceq
  \mathsf{Sample}(U,d,x_1,\ldots,x_t,x_{t+1}).
\]
Equality is allowed when the next input produces no output. Thus $D_t$ could
equivalently be obtained by computing any later $D_{t'}$ and discarding its
suffix. The ideal experiment chooses one hidden random tape $r_d$ for the
fixed description and evaluates all public-input prefixes consistently on
that tape. An instance identifier can be included in $d$ to obtain independent
streams.

The separation between $d$ and the $x_i$ is essential. The description need
not be secret, but it is fixed and determines which internal values may ever
be output. Public inputs are data, not new circuit instructions. If an
adversary could extend $d$ itself, it could append an output wire exposing an
earlier random input---for example, a secret key used by the garbling. A
malicious alternative description $d'$ instead receives independent sampler
coins and does not expose the state of the protected stream for $d$.

The desired security experiment otherwise follows adaptive universal
sampling, now allowing the public inputs to be chosen after earlier output
prefixes have been observed. Its treatment of forked input histories and
off-path queries must be made explicit. A complete definition and a
construction under useful assumptions remain open; every efficient execution
supplies and observes only a polynomial prefix.

\subsection{An infinitely garbled computation}

Let a public transition circuit compute
\[
  F(s_t,a_t)=(s_{t+1},y_t),
\]
where $s_t$ is private carried state, $a_t$ is fresh external input, and
$y_t$ is the public output at time $t$. Unroll $F$ into one infinite circuit
with stretches $F_0,F_1,\ldots$. Fix one streamer description $d_F$ whose
protected computation performs a prefix-preserving garbling of these
stretches. The public streamer input $z_t$ contains the canonical batch of
newly registered public keys and other public instance data used for stretch
$F_t$. All parties compute
\[
  D_t=\mathsf{Sample}(U,d_F,z_0,\ldots,z_t).
\]
The code and output policy of $d_F$ never change. Only the public data $z_t$
are appended, so a corrupt party cannot add an instruction exposing an
internal garbling key. The description decides how the new public keys are
used to form ciphertexts for the next computation roles.

For every state bit $j$ and time boundary $t$, the hidden computation of $d_F$
samples a fresh pair
$(K^{s}_{t,j,0},K^{s}_{t,j,1})$. These are the labels of one boundary wire:
the output label pair of stretch $F_{t-1}$ is literally the input label pair
of stretch $F_t$. The pair is fresh at each new boundary; it is not one label
pair reused for all time. The protected state of $d_F$ can use both labels of
the preceding boundary wire when garbling $F_t$, even though the pair was not
exposed by $D_{t-1}$. The new output suffix contains public garbled tables,
public decoding information for $y_t$, and ciphertexts under the keys in
$z_t$ for committees holding fresh external-input labels. It never contains
both raw labels of a wire.

Suppose the common public protocol view determined by $L$ contains one active
state label $K^s_{t,j,s_{t,j}}$ for every state-input wire of $F_t$. For
$t=0$, these labels must be bootstrapped either from a fixed initial state or
by the same protected-input mechanism used below. The online step is then:
\begin{enumerate}
  \item Each named input provider uses protected evaluation to append the
    activation token representing its fresh input bit.
  \item For every external-input wire, only the selected computation
    committee reveals enough keys to reconstruct its active input label. Its
    sibling committee remains silent forever.
  \item Everyone now has one active label for every input wire of $F_t$ and
    publicly evaluates the next garbled stretch.
  \item Evaluation reveals the decoded output $y_t$ and one active label
    $K^s_{t+1,j,s_{t+1,j}}$ for each next-state wire. These labels become
    common public values deterministically derived from the ledger prefix and
    the streamer output; they need not be appended as separate entries. They
    are already the state-input labels for $F_{t+1}$.
\end{enumerate}

No committee is needed for an internal or carried-state label. Once active,
such a label is publicly computable from the garbled tables and active input
labels; only its inactive sibling must remain hidden. Committees and silence
are used precisely where genuinely new private external inputs enter the
computation (and, in future variants, where a private output must be
delivered).

The round boundaries are therefore protocol boundaries caused by input
arrival, not boundaries between independently garbled circuits. There is no
reactive linker holding both old and new label pairs: adjacent stretches share
the same boundary wires by construction.

For every finite number $T$ of steps, the public input prefix
$(z_0,\ldots,z_T)$ and output $D_T$ are finite and polynomially computable.
Prefix preservation gives $D_T\preceq D_{T+1}$, so supplying the next batch of
registered keys does not alter anything already used. Public availability of
future garbled tables is
harmless by itself, since evaluation still requires the unique active state
labels and the input labels released by the selected committees.

\subsection{What remains open}

The preceding argument identifies what an ideal universal streamer would buy;
it is not yet a construction or a simulation proof. The central cryptographic
problem is to produce one finite public parameter $U$ that lets the fixed
description retain hidden correlated state while public inputs and outputs
grow, even when each next input is chosen after all preceding output is known.
The definition must settle independent instances, forked input histories, and
off-path evaluations of the public sampling algorithm. It must also state the
admissibility condition on $d_F$ under which its fixed output policy constitutes
a secure prefix-preserving garbling.

At the ideal level, new recipient keys require no command of
$\mathcal F_{\mathsf{Ledger}}$ and no separate linking party: the keys are
fields of the next public input $z_t$, while $d_F$ determines how they extend
the garbling. Whether existing universal-sampler techniques can realize this
adaptive, prefix-preserving use with the required simulation guarantees is open. An
apparently infinite execution also has to be interpreted
cryptographically: every efficient environment reaches only a polynomial
prefix. A literal all-time reliability statement would instead require a
summable failure budget, for example committee sizes that grow slowly with
the step number.

Reactive garbling \cite{NielsenRanellucci2015ReactiveGarbling}, succinct
garbling \cite{LinPass2014SuccinctGarbling}, cryptographic iterators
\cite{KoppulaLewkoWaters2014IOTM}, reusable garbled circuits and garbled
Turing machines
\cite{GoldwasserEtAl2012ReusableGarbling,GoldwasserEtAl2013TuringMachines},
and streaming functional encryption
\cite{GuanKorbSahai2022StreamingFE,BhushanKorbSahai2024StreamingFE,DattaGuanKorbSahai2024AdaptiveStreamingFE}
remain relevant candidates for realizing parts of the abstraction. The
motivation above, however, needs none of their usual reactive linking
interfaces: it asks first for a fixed protected sampling description with
prefix-preserving output under a growing public input stream.
