# Previous manuscript

This directory preserves the local manuscript as it stood on 2026-10-01,
including uncommitted chapter edits. It is historical material and is not
included by the new top-level `main.tex`.

`main.tex`, `macros.tex`, both bibliography files, `Makefile`, and `sections/`
form a snapshot of the previous source. `previous-draft.pdf` is the existing
PDF copied at the same time; it has not been rebuilt or checked against the
snapshot. The new manuscript is being developed section by section.
