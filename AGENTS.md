# Shared manuscript instructions

Everything tracked here is public and may be synchronized to the coauthor
Overleaf project.

- Keep this repository limited to publication-ready LaTeX, figures, and
  bibliography entries.
- Do not add downloaded papers, private notes, correspondence, credentials,
  tokens, scratch work, or unreviewed proof attempts.
- Pull current changes before editing.
- Preserve coauthor edits and surface overlapping changes or merge conflicts.
- Compile `main.tex` with `make` after every substantive change.
- Inspect the full diff before committing.
- Pull immediately before editing and again before pushing.
- Do not push without an explicit user instruction in the current task.
- Never force-push.
