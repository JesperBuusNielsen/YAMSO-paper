# Shared manuscript instructions

Everything tracked here is public and may be synchronized to the coauthor
Overleaf project.

- Keep this repository limited to publication-ready LaTeX, figures, and
  bibliography entries.
- Do not add downloaded papers, private notes, correspondence, credentials,
  tokens, scratch work, or unreviewed proof attempts.
- Before editing, fetch and integrate current changes from both `origin`
  (GitHub) and the direct `overleaf` remote; see `OVERLEAF.md`.
- Preserve coauthor edits and surface overlapping changes or merge conflicts.
- Compile `main.tex` with `make` after every substantive change.
- Inspect the full diff before committing.
- Recheck both remotes immediately before pushing and integrate new changes.
- `pull-sync` authorizes local integration, checkpoint commits, and a build,
  but no push. `full-sync` explicitly authorizes committing and pushing the
  reviewed shared changes to both remotes without another confirmation.
- Otherwise, do not push without an explicit user instruction.
- Never force-push.
